## 2. ריילי ETH/SOL חיים (evm-wire + sol-wire)

- **`src/lib/dex/evm-wire.ts`**: ארנק EVM מהכספת (אימות כתובת מול הרשומה לפני כל שידור), מאזן חי דרך eth.drpc.org (+2 גיבויים), שידור EIP-1559 עם תקרת-גז (80 gwei) וקבלת NO-GAS כנה.
- **`src/lib/dex/sol-wire.ts`**: זוג-מפתחות ed25519 מ-hex-seed של הכספת (node:crypto — אפס תלות חדשה), **בניית legacy-tx ביד** (compact-u16 + message + חתימה), שידור דרך api.mainnet-beta.solana.com.
- **`/api/money/eth` + `/api/money/sol`**: GET מדידה חיה (מאזני 12 החשבונות + מחיר binance + אימות נגזרות), POST שידור דרך שער-$100.
- **הוכחה בשרשרת**: ההעברה מ-R102 בוצעה מהכספת ועד לאישור-בלוק — הפעולה הכספית הראשונה של הרשת מחוץ לעולם הגרפן.

## 3. זירת-המסחר הריבונית (`sovereign-exchange.ts` + `/api/exchange`)

**החוקה** (מנגנון, לא הבטחה):
- **ספר-פנים hash-chained** — `ExchangeEvent` עם `hash = keccak(prevHash‖seq‖kind‖member‖payload)` — אותה שיטת ספר של האימותים. החישוב-חדש מאומת בכל תמונה (`bookIntegrity.recomputeOk: true`).
- **USDS בגיבוי-רזרבה מלא** — הטבעה רק מול נעילת SBD/HBD (1:1), פדיון שורף 1:1. **היצע = רזרבה, תמיד** — שמירת-הערך במבנה, לא בהבטחה.
- **נכסים-עטופים 1:1** — WSTEEM/WSBD/WHIVE/WHBD/WBLURT נזקפים מהון-אוצר נמדד (90% — 10% דלק-שידור) או מהפקדות; משיכה שורפת עטיפה ומשדרת העברה אמיתית.
- **בריכות AMM קבועות-מכפלה, עמלת 30bps** — העמלה נשארת בבריכה (ערך ה-LP של האוצר): **"העמלות ייגזרו בבריכות שלנו"**.
- **דלת-הפקדות ציבורית** — memo `wx:<member>` לאוצר ב-STEEM; סריקת היסטוריה מאמתת מול השרשרת, אידמפוטנטית לפי txid.
- **שער-$100** — משיכה מתחת לסף מבוצעת אוטונומית; מהסף — תור-מפעיל (אותו חוק אחד).

**הוכחות חיות מהסשן:**
| פעולה | קבלה |
|---|---|
| ג'נזיס מהון נמדד | 4 אירועים, הספר מאומת |
| USDS מוטבע מול נעילת SBD | 0.035 USDS = 0.035 WSBD נעול |
| החלפה 1: 50 SAOS ← USDS | seq 5, מחיר-גילוי חי |
| החלפה 2 (multi-hop): USDS ← WBLURT | seq 6 — זרימה רב-מסלולית |
| **משיכה 0.005 WSBD** | **txid 4e90bfda… — העברת-STEEM אמיתית ל-cashmachine, שער EXECUTED** |
| החלפה מהדפדפן (UI) | "הוחלף 50 SAOS ← 0.001551871 USDS (עמלה 30bps לבריכה)" |

**זירת הדולר של BLURT** — בריכת WBLURT/USDS חיה עם גילוי-מחיר אמיתי (0.00189 USDS/BLURT אחרי המסחר) — חסימת BLURT נפתחה ל-PARTIAL-LIVE; הנותר בכנות: רייל-משיכה (chain_id של Blurt לא אומת מה-RPC — לא מנחשים).

1. אימות chain_id של Blurt ממקור רשמי → שידור-הוכחה → פתיחת רייל-המשיכה (בדיוק כמו SOL).

4. הזרמת הפאוורדאון השבועי לבריכות (עומק אמיתי גדל).
