### 2.2 חוק שומר-הפעימה (money v1.9.0)
האינטרוול עצמו בודק את השומר שלפניו:
```ts
G.__MONEY_TIMER__ = setInterval(() => {
  if (ticking && tickStartedAt && now - tickStartedAt > TICK_MAX_MS) {   // 5 דק'
    ticking = false;   // שחרור בכוח + רשומת-אמת WATCHDOG-RELEASE
  }
  if (state.acting && actStartedAt && now - actStartedAt > ACTING_MAX_MS) { // 10 דק'
    state.acting = false;   // שחרור כנה + תיעוד
  }
  tick();
}, CHECK_INTERVAL_SEC * 1000);
```
פעימה תלויה עולה מחיר מחזור אחד, לא מחיר הדיבון. ה-await היתום שנשאר חסר-כוח-כתיבה (נבדק: אחרי נקודת התלייה אין כתיבות-מצב בשרשרת-הקריאה).
